# حلول بصرية

حلول بصرية هو موقع احترافي لعرض خدمات الدعاية والإعلان والطباعة، تم بناؤه باستخدام Next.js و Tailwind CSS.

## المميزات
- صفحة رئيسية احترافية
- صفحات: من نحن، خدماتنا، أعمالنا، المدونة، تواصل معنا
- لوحة تحكم مخفية خلف رابط مباشر وتسجيل دخول
- إدارة خدمات، مقالات، أعمال، ومستخدمين
- دعم الصور المحلية وتحسين تحميلها
- تصميم متجاوب ومتوافق مع جميع الأجهزة

## المتطلبات
- Node.js 18+
- npm أو yarn

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح العنوان التالي في المتصفح:

http://localhost:3000

## لوحة التحكم
رابط الدخول المباشر:

http://localhost:3000/admin/login

اسم المستخدم الافتراضي:
- admin

كلمة المرور الافتراضية:
- admin123

## النشر
يمكن ربط المشروع بسهولة على Vercel، مع إعداد متغيرات البيئة:

```bash
JWT_SECRET=your-secret-key
```

## هيكل المشروع
```bash
app/
  admin/
  api/
  blog/
  contact/
  etc...
components/
lib/
public/
data/
```

## ملاحظات
- يتم حفظ بيانات المحتوى في مجلد `data/` داخل المشروع.
- الصور محفوظة داخل `public/uploads/` ويمكن رفعها مباشرة من لوحة التحكم.
- هذا المشروع قابل للتطوير إلى نظام إدارة كامل مع قاعدة بيانات حقيقية لاحقاً.
